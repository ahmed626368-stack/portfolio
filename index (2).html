عني


طالب في السنة النهائية بكلية الحوسبة وتقنية المعلومات (هندسة النظم والحاسبات) بالجامعة العربية المفتوحة، تخرّج متوقع 2027. تخصصي الأمن الهجومي، وبشتغل عمليًا على أدوات اختبار الاختراق، وببني أدواتي الأمنية بنفسي.











المشاريع









حسابات العمل الحر


نفس التخصص على المنصات التلاتة: اختبار اختراق تطبيقات الويب وتقييم الثغرات. بس كل منصة بتتباع بطريقة مختلفة.











العرض الفني والمالي


عرض لعميل طلب "Comprehensive Web Application Penetration Test & Vulnerability Assessment". المنهجية: OWASP Top 10:2025 وWSTG وPTES، والتقييم بـ CVSS v3.1.






النطاق والتسليمات
داخل النطاق: التطبيق المتفق عليه قبل وبعد تسجيل الدخول، كل الـ endpoints والـ parameters، حتى دورين للمستخدمين، والمنافذ والخدمات المكشوفة للسيرفر.
خارج النطاق: اختبارات DoS والحمل، الهندسة الاجتماعية، الأمن المادي، خدمات الأطراف الثالثة، وتطبيقات الموبايل.
التسليمات: ملخص تنفيذي، تفاصيل كل ثغرة (PoC وخطوات إعادة الإنتاج والأثر وCVSS والإصلاح)، مصفوفة مخاطر، خارطة إصلاح، ملحق أدلة، وتقرير إعادة الفحص.


تقييم الخطورة (CVSS v3.1) وزمن الإصلاح
  • Critical (9.0 إلى 10): خلال 7 أيام
  • High (7.0 إلى 8.9): خلال 14 يوم
  • Medium (4.0 إلى 6.9): خلال 30 يوم
  • Low (0.1 إلى 3.9): الإصدار القادم

القيمة المميزة


لا أكتفي بتشغيل أدوات الفحص؛ أفكّر كالمخترق وأكتب كالمهندس. أختبر تطبيقات الويب يدويًا بتدريب عملي ضمن مسار DEPI، وأُثبت كل ثغرة بدليل حيّ، وأسلّمك خطة إصلاح واضحة ومرتّبة بالأولوية.


I don't just run scanners. I think like an attacker and report like an engineer: manual web testing with Burp Suite, Nmap and Metasploit, a working PoC for every finding, and a prioritized fix list so you remove real risk, not scanner noise.
